# Эмулятор командной строки (GUI)

Графический эмулятор языка оболочки UNIX-подобной ОС.

## Общее описание

Эмулятор реализован на Python с использованием стандартной
библиотеки `tkinter`. Окно приложения состоит из:

- области вывода — показывает историю введённых команд и
  результаты их выполнения;
- строки ввода — куда пользователь вводит команды.

## Этап 1. REPL

На этом этапе реализован минимальный прототип:

- простой парсер, разбивающий ввод на команду и аргументы по
  пробелам;
- команды-заглушки `ls` и `cd`, которые выводят своё имя и
  переданные аргументы;
- команда `exit`, завершающая работу приложения;
- обработка неизвестных команд с выводом сообщения об ошибке.

## Этап 2. Конфигурация

Эмулятор поддерживает параметры командной строки и стартовый
скрипт:

- `--vfs-path` — путь к физическому расположению VFS (JSON-файл).
  Используется для формирования имени VFS в заголовке окна.
- `--script` — путь к стартовому скрипту с командами эмулятора.
  Скрипт выполняется автоматически при запуске, каждая команда
  отображается в логе как если бы её ввёл пользователь, после чего исполняется.

Стартовый скрипт поддерживает комментарии: строка, начинающаяся 
с символа `#`, игнорируется. Пустые
строки также пропускаются.

При запуске всегда выводится отладочная информация о
переданных параметрах (даже если они не заданы).

Если во время выполнения стартового скрипта происходит ошибка, она выводится, 
а работа приложения продолжается.

## Этап 3. VFS

Если указан параметр `--vfs-path`, эмулятор при запуске целиком
загружает VFS в память из JSON-файла. VFS  представлена 
деревом директорий и файлов; бинарное содержимое
файлов хранится в исходном JSON в кодировке base64. Никакие
операции не модифицируют исходный JSON-файл на диске — всё дерево
живёт только в оперативной памяти процесса.

Формат JSON-файла VFS:

```json
{
  "name": "my_vfs",
  "children": [
    {"name": "file.txt", "type": "file", "content_base64": "..."},
    {"name": "subdir", "type": "dir", "children": [
      {"name": "nested.txt", "type": "file", "content_base64": "..."}
    ]}
  ]
}
```

Если имя VFS указано в самом JSON-файле (поле `name`), оно
подставляется в заголовок окна вместо имени, вычисленного по имени
файла.

Добавлена служебная команда `vfs-info`, которая выводит имя
загруженной VFS и SHA-256 хеш исходных байт JSON-файла. Если VFS не
была загружена (параметр `--vfs-path` не указан или загрузка
завершилась ошибкой), команда сообщает об ошибке.

Ошибки загрузки VFS не прерывают запуск приложения — эмулятор продолжает
работать без VFS, а причина ошибки выводится в лог.

Примеры готовых VFS для тестирования лежат в папке `vfs/`:
- `minimal_vfs.json` — пустая VFS без единого файла;
- `multi_file_vfs.json` — несколько файлов на одном уровне, включая
  файл с бинарными данными;
- `deep_vfs.json` — вложенность в 3 уровня директорий.


## Функции и настройки

| Команда / параметр | Описание |
|---|---|
| `ls [аргументы]` | Заглушка — выводит `ls: <аргументы>` |
| `cd [аргументы]` | Заглушка — выводит `cd: <аргументы>` |
| `vfs-info` | Выводит имя загруженной VFS и её SHA-256 хеш |
| `exit` | Завершает работу приложения |
| `--vfs-path <путь>` | Путь к JSON-файлу VFS |
| `--script <путь>` | Путь к стартовому скрипту эмулятора |

## Сборка и запуск

В проекте используется только стандартная библиотека Python `tkinter`.

Запуск приложения:

```bash
python3 src/emulator.py
```

Запуск с указанием VFS и стартового скрипта:

```bash
python3 src/emulator.py --vfs-path vfs/deep_vfs.json --script scripts/startup_stage3_full.txt```
```

Готовые тестовые скрипты для всех комбинаций параметров лежат в
папке `scripts/`:
- `test_no_params`, `test_vfs_only`, `test_script_only`, `test_full`
  — комбинации параметров командной строки (Этап 2);
- `test_vfs_minimal`, `test_vfs_multi`, `test_vfs_deep` — разные
  варианты VFS (Этап 3);
- `test_vfs_info_error` — обработка ошибки vfs-info без VFS.

## Примеры использования

После запуска в открывшемся окне можно ввести, например:

```
$ ls -la /home
ls: -la /home
$ cd /var/log
cd: /var/log
$ vfs-info
Имя VFS: deep_vfs
SHA-256: 81bc69e0cef32bf8...
$ foo
Ошибка: неизвестная команда 'foo'
$ exit
```


Отладочный вывод параметров запуска:
```
  Путь к VFS: vfs/deep_vfs.json
  Путь к стартовому скрипту: scripts/startup_stage3_full.txt
VFS 'deep_vfs' успешно загружена.
```

Пример вызова `vfs-info` без загруженной VFS:

```
$ vfs-info
Ошибка: VFS не загружена
```

Пример выполнения стартового скрипта (комментарии в файле
пропускаются):

```
$ ls -la /home
ls: -la /home
$ cd /var/log
cd: /var/log
$ vfs-info
Имя VFS: deep_vfs
SHA-256: 81bc69e0cef32bf8...
$ unknown_command foo bar
Ошибка: неизвестная команда 'unknown_command'
$ exit
```

## Тестирование

Тесты для модулей `emulator.py` и `vfs.py` находятся в каталоге
`tests/`. Запуск всех тестов:

```bash
python3 -m unittest discover -s tests
```
